EventEmitter Behavior

EventEmitter emits 'newListener' before a listener is added
EventEmitter emits 'removeListener' after a listener is removed
EventEmitter emits 'error' when an 'error' event is emitted without a listener
EventEmitter supports listener context through this
EventEmitter supports multiple listeners for the same event
EventEmitter preserves listener registration order
EventEmitter.once() removes its listener after the first invocation
EventEmitter supports Symbol event names
EventEmitter supports listener-count limits
EventEmitter supports Promise-based once()
EventEmitter supports async iteration through EventEmitter.on()
EventEmitter supports AbortSignal cancellation through EventEmitter.addAbortListener()
EventEmitter supports captureRejections
EventEmitter supports EventTarget interoperability for applicable static methods
